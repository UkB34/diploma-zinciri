Test imza anahtarlarını oluştur

Öğrenci işleri, fakülte, rektörlük ve merkez için dört ayrı test anahtarı üretir. Anahtarlar bu tarayıcıda oluşturulur; bu sayfa hiçbir sunucuya veri göndermez. Bunlar nitelikli elektronik imza sertifikası değildir.

Cloudflare’da SIGNING_KEYS_JSON zaten varsa yeni anahtar üretmeyin. Mevcut anahtarları değiştirmek bekleyen davetleri geçersiz kılar.

Cloudflare → Runtime variables and secrets → Production → Add variable. Tür: Secret, ad: SIGNING_KEYS_JSON. Aşağıdaki değerin tamamını Value alanına yapıştırıp kaydedin.

Anahtar değerini sohbete veya GitHub’a göndermeyin. Cloudflare’a kaydettikten sonra bu sayfayı kapatabilirsiniz. Sayfa yenilenirse burada üretilen değer kaybolur.
